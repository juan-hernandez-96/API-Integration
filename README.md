# API-Integration

# The following projects were done with the purpose of a better understandment of the use, application, and management of APIs in web services. Each of the following programs were done using an API in mind: A map location API, a social media API, a data base API, and a streamimg service API. 

# 1. Geolocalization API-
This program uses OpenLayer and OpenStreetMap to showcase the use of an interactive map in a web application, in this the user can zoom in and out and click on the map to obtain the coordenates of a place, as well as the name and general address of where the user locates the pointer.

# 2. DataBase API-
This program uses the API obtained from the website Clever Cloud which can be connected to MySQL in order to retrieve data from a data base done in the MySQL Workbench.

# 3. Social Media API-
This program uses the bluesky API to call on the most recent post made by any user that's registered on the main app.

# 4. Stream API-
Using Deezer API, the program calls on the information for a song by name, where it returns the name of the song, the artist, the cover of the album, and a snippet of the song.
